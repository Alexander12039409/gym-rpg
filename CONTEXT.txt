Gym RPG v4 — контекст для следующего чата
===========================================
Скопируй этот файл целиком в новый чат, если ассистент «забыл» проект.

ГДЕ ЛЕЖИТ
- Рабочая папка: E:\gym app\gym-rpg-v4\
- Запуск: открыть gym-rpg-v4\index.html в браузере (file://). Сборки нет.
- Опционально: node "E:\gym app\gym-rpg-v4\serve.js" → http://127.0.0.1:8767/
- v3 (архив, не трогать): E:\gym app\gym-rpg-v3\  ключ gymRpgV7, порт 8766
- v2: E:\gym app\gym-rpg-v2\  ключ gymRpgV6, порт 8765
- v1: E:\gym app\  ключ gymRpgV4
- Сохранение v4: localStorage ключ gymRpgV8 (старые ключи не подхватятся)
- Telegram Mini App: js/tg.js + telegram-web-app.js. В WebView сейв ещё пишется в CloudStorage бота (чанки g8n/g8c*). Инструкция: TELEGRAM.md.
- Кросс-девайс работает только внутри Mini App одного и того же бота + того же Telegram-аккаунта. Браузер без Telegram = только localStorage.

ЧТО ЭТО
Логер тренировок в шкуре RPG. Сет = удар по боссу. HTML+CSS+JS, графика в assets/.
Тон: качалка, ирония, мат.

ВИЗУАЛЬНЫЙ СТИЛЬ
Punch Club / adult cartoon: толстый чёрный контур, плоский насыщенный цвет, простое cel-shade,
яркая кремово-жёлтая бумага, красный / лайм / синий / золото. Кнопки, шкалы, карточки —
3px чёрная обводка + нижняя тень.

ЯДРО ЛОГИКИ (не ломать без нужды)
- Игрок заранее создаёт ПЛАНЫ и ДНИ. Перед боем выбирает план+день в нижней шторке.
- У упражнения: название, описание, галка «можно со своим весом». Подходы кидают в бою.
- Прогрессия 1.2 / 0.8 / 0.62, галка разгрузки. HP босса между сессиями, оверкилл на следующего.
- После сюжетных — endless «Король Реванша».
- Случайные события ~17%, кулдаун 2 сета.

ГЕРОЙ / СОЗДАНИЕ
- После веса и роста: карусель типов фигуры (пол → свои картинки). Чипс: жир% / мышцы% + текст.
  Типы: Палка, Скинни-фэт, Нормис, Мягкий запас, Крепыш, Атлет.
  Картинки: assets/hero/body-{m|f}-{id}.png
- Затем тренировочный стаж (нулевой / новичок / уже хожу / опытный / ветеран) + дескрипшн.
  Нулевым и новичкам — предупреждение про тренера и технику.
- После «Создать героя» — экран-саммари: фигура, стаж, 2–3 рекомендованных программы (добавить в книгу).
- Клик по всей шапке открывает экран героя: саммари, случайный лучший подход из летописи, «Редактировать».
- Проблемные зоны и цель как в v3. Стартовый портрет от зоны, путь титулов = пол × цель.

ПЛАНЫ
- Пул шаблонов PROGRAM_PACKS: Сплит 3 дня, Сплит 4 дня, Фуллбади 3/4, Тяни-толкай, Собственный вес.
- На вкладке Планы блок «Популярные программы». templateId, чтобы не дублировать.

УВЕДОМЛЕНИЯ
- Если нет тренировки NUDGE_AFTER_DAYS (4) дней — модалка «Время качаться, соберись» + случайная цитата из QUOTES (кино/книги/пословицы) и источник.
- Кнопки «Я помню» / «Я слабый гой» закрывают. Повтор не чаще чем раз в 20 часов (lastNudgeAt).

КАРТА / БОЙ / ПУТЬ / UX
- Как в v3: вертикальная карта, градиент, Catmull-Rom дорога, конфетный таббар (подпись только у активной).
- Клавиатура: шторка с копией поля, в бою поля в шторке.
