# Gym RPG

Логер тренировок в шкуре RPG. Сет = удар по боссу.

Статика: HTML / CSS / JS, сборки нет. Локально: `node serve.js` → http://127.0.0.1:8767/

В Telegram Mini App прогресс пишется в CloudStorage бота (тот же Telegram-аккаунт, любой телефон). В браузере — `localStorage`.

Как выложить Mini App: см. `TELEGRAM.md`.
